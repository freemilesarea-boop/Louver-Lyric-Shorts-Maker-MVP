  다음 실행부터는 응용 프로그램 폴더에서 더블클릭만
  하면 됩니다.


  왜 .command 파일이 필요한가요?
  ─────────────────────────────

  Lyric Shorts Maker는 아직 Apple Developer ID
  ($99/년) 인증서가 없는 RC 테스트 빌드입니다.

  macOS Sequoia (15.x) 부터 Apple이 미인증 앱
  실행을 매우 엄격하게 막고 있어서, 일반적인
  "시스템 설정 → 그래도 열기" 경로가 더 이상
  작동하지 않습니다.

  .command 파일은 macOS의 "quarantine" 격리
  속성을 제거해서 앱이 정상 실행되게 해줍니다.

  앱 자체는 안전합니다 — 소스 코드 GitHub 공개:
  https://github.com/freemilesarea-boop/Louver-Lyric-Shorts-Maker-MVP


  ⚠️  ".command 파일도 손상되었다고 나올 경우"
  ──────────────────────────────────────────

  드물지만 .command 파일도 격리되는 경우가 있어요.
  그땐 한 번만 터미널 명령이 필요합니다:

    1) Spotlight (Command+Space) → "터미널" 입력 → 엔터
    2) 아래 한 줄을 복사해서 터미널에 붙여넣고 엔터:

       xattr -dr com.apple.quarantine "/Applications/Lyric Shorts Maker.app"

    3) Mac 사용자 비밀번호 입력 → 엔터

    4) 응용 프로그램 폴더에서 Lyric Shorts Maker 더블클릭

  그 후 다시 터미널 쓸 일 없습니다.


  ════════════════════════════════════════════════════
  macOS 14 (Sonoma) 또는 이전 사용자만 — 시스템 설정 경로
  ════════════════════════════════════════════════════

  Sonoma 14 이전 버전에서는 다음 경로도 작동합니다:

    1) 응용 프로그램에서 Lyric Shorts Maker 더블클릭
       → "확인되지 않은 개발자" 경고 → "확인" 클릭

    2) Apple 메뉴 → 시스템 설정 → 개인정보 및 보안
       → 아래로 스크롤 → "Lyric Shorts Maker 차단됨"
       → "그래도 열기" 클릭

    3) 비밀번호/Touch ID 인증 → 확인 다이얼로그 → "열기"

  ⚠️ Sequoia (15.x) 사용자는 이 경로 작동 안 됨.
     위의 .command 파일 방식을 사용하세요.
