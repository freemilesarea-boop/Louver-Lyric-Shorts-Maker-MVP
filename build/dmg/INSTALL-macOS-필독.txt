  Lyric Shorts Maker — macOS 설치 방법
═══════════════════════════════════════════════════════════


  ❶ Lyric Shorts Maker.app을 Applications 폴더로 드래그

  ❷ 아래 명령 한 줄을 터미널에 붙여넣고 Enter
     (한 번만 실행하면 됩니다)

  ┌────────────────────────────────────────────────────────┐
  │                                                        │
  │   xattr -dr com.apple.quarantine \                     │
  │       "/Applications/Lyric Shorts Maker.app"           │
  │                                                        │
  └────────────────────────────────────────────────────────┘

     ▸ Spotlight 열기 (⌘ + Space)
     ▸ "터미널" 입력 → Enter
     ▸ 위 명령 복사 → 터미널에 붙여넣기 → Enter
     ▸ Mac 비밀번호 입력 (타이핑은 화면에 안 보임, 정상) → Enter

  ❸ 응용 프로그램 폴더에서 Lyric Shorts Maker 더블클릭

  ✅ 완료. 다음부터는 더블클릭으로 바로 실행됩니다.


═══════════════════════════════════════════════════════════


  왜 이 명령이 필요한가요?
  ─────────────────────────

  Lyric Shorts Maker는 아직 Apple Developer ID 인증서
  ($99/년) 없이 출하되는 RC 테스트 빌드입니다.

  macOS Sequoia (15.x) 부터 Apple이 미인증 앱 실행을
  더 엄격하게 막아서, 평소의 "시스템 설정 → 그래도 열기"
  경로가 작동하지 않습니다.

  위 한 줄은 macOS의 quarantine (격리) 속성을 한 번만
  제거합니다. 이후엔 터미널을 다시 쓸 일이 없습니다.

  소스 코드는 GitHub에 공개되어 있습니다:
  https://github.com/freemilesarea-boop/Louver-Lyric-Shorts-Maker-MVP

  정식 V1.0.0 부터는 Developer ID 인증서를 적용해서
  이 단계가 불필요하게 만들 예정입니다.
